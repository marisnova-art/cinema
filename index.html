CONNECTYOUR KEYS

파일 상단 CONFIG에 키를 넣어두는 방식을 권장합니다. 여기서 입력한 값은 CONFIG가 비어 있을 때만 쓰이며, 이 브라우저에만 저장됩니다.

Anon 키와 아래 SQL의 정책은 “키를 가진 사람은 누구나 읽고 쓸 수 있는” 개인용 구성입니다. 이 HTML을 공개하지 마세요.

  1. TMDB에 로그인 → 설정 → API에서 키를 발급받습니다.
  2. Supabase 프로젝트를 만들고 SQL Editor에서 아래 SQL을 한 번 실행합니다.
  3. Project Settings → API에서 Project URL과 anon(public) 키를 복사해 입력합니다.
